# YanXi for TuneLab

TuneLab で嫣汐（イエンシー / YanXi）を歌わせるボイスプラグインです。

- **インストールするだけで歌えます** — 嫣汐の音源データをこの拡張に同梱しているので、
  MUTA 本体を別途インストールする必要はありません。
- 同じ音源で中国語と日本語の両方が歌えます（言語はパート設定）。
- ピッチ、ビブラート、オートメーション、音素の固定、ノート単位のサンプル音域シフト、
  手動ブレスは TuneLab のエディタから操作できます。
- worldline R1.1 を内蔵。外部のニューラルボコーダ設定は不要です。
- 他の MUTA 音源も使いたい場合は「設定 → 拡張機能 → 嫣汐」でフォルダを追加すると、
  音源リストに 嫣汐 と並んで表示されます。
